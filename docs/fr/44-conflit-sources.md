# Conflit de sources

Dans `prototype/hyperliquid_provenance.py`, ce travail étudie la procédure en cas de valeurs divergentes. La fiche distingue la donnée d’entrée, la règle calculée et la limite de confiance afin de rendre l’analyse vérifiable par un tiers. Elle complète les exemples de domaine sans transformer un prototype en garantie de protocole.

Aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
