# Pliage FRI

stark_fri_fold.py présente une étape de pliage utilisée pour réduire un polynôme évalué. Le pliage combine des valeurs selon un défi et produit une instance de taille moindre. Les défis doivent rester liés au transcript afin d’éviter une preuve interchangeable.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
