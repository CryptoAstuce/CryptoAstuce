# Donnée absente

Dans `prototype/rollup_data_availability.py`, ce travail étudie la réponse attendue lorsqu’une donnée manque. La fiche explicite la donnée observée, la condition de validité et le risque d’une interprétation trop large, pour conserver une documentation exploitable par un autre lecteur. Elle complète le parcours français sans revendiquer de résultat non observé.

Aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
