# Frontières d’un rollup

Le prototype de disponibilité des données sépare les responsabilités du producteur, du relais et du vérificateur. Ces frontières permettent de localiser une hypothèse de confiance. Le chapitre recommande de noter les erreurs observables à chaque étape.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
