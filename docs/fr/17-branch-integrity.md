# Intégrité de branche

La branche main est la référence retenue pour le suivi de ce dépôt original. Un audit doit confirmer le commit présent sur cette branche et éviter une branche de travail isolée. La branche et l’URL du commit font partie de la preuve publiée.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
