# Trace d’API

Dans `prototype/hyperliquid_provenance.py`, ce travail étudie la traçabilité d’une requête sans exposer de secret. La fiche distingue la donnée d’entrée, la règle calculée et la limite de confiance afin de rendre l’analyse vérifiable par un tiers. Elle complète les exemples de domaine sans transformer un prototype en garantie de protocole.

Aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
