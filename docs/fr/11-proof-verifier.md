# Vérificateur STARK

stark_proof_verifier.py assemble les contrôles nécessaires à une vérification de preuve. Un vérificateur doit valider les engagements, les ouvertures, les contraintes et les paramètres. La présence d’un prototype ne prouve pas que tous les cas limites sont couverts.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
