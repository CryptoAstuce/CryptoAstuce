# Visibilité publique

Une contribution ne peut être comptée comme publique que si le dépôt et le commit sont accessibles sans autorisation privée. La visibilité doit être contrôlée au moment de la vérification, pas déduite d’un ancien état. Cette règle est essentielle pour rapprocher historique GitHub et compteur Guild.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
