# Colonnes de trace

Dans `prototype/stark_trace_arithmetization.py`, ce travail étudie le rôle des colonnes pour représenter une exécution. La lecture relie ce mécanisme aux entrées et sorties visibles du prototype afin de séparer la garantie locale des hypothèses cryptographiques externes. Cette fiche sert de référence pour une revue indépendante et ne prétend pas remplacer une implémentation de production.

Aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
