# Disponibilité des données rollup

rollup_data_availability.py explore les données nécessaires à la reconstruction d’un état de rollup. Il faut distinguer publication, disponibilité, récupération et vérification. Une donnée annoncée comme disponible ne suffit pas si le chemin de récupération n’est pas défini.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
