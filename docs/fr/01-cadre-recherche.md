# Cadre de recherche

Le dépôt présente une recherche appliquée sur ZK, FHE, Base et HyperEVM. Ce chapitre fixe les questions, les hypothèses et la séparation entre faits observés et interprétations. Les sources directes restent les fichiers publics de prototype et leur documentation.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
