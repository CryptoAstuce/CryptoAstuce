# Trace STARK

stark_trace_arithmetization.py modélise la transformation d’une exécution en trace arithmétisée. La trace expose des colonnes et des relations qui peuvent ensuite être contraintes. L’exemple sert à expliquer le lien entre calcul natif et représentation vérifiable.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
