# Attribution d’auteur

Le prototype de classification distingue l’identité de l’auteur et le contenu du changement. Pour un audit GitHub, l’auteur visible, la branche et la visibilité du dépôt doivent être relevés directement. Un compteur externe peut appliquer des règles différentes de l’historique GitHub affiché.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
