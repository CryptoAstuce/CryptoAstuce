# Preuves récursives

La récursion combine une preuve existante avec une nouvelle instance de vérification. Elle réduit potentiellement la surface de publication mais ajoute des relations de composition. Les paramètres du vérificateur interne et externe doivent être documentés séparément.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
