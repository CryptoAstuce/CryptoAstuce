# Reproductibilité

Le README du prototype décrit un parcours reproductible pour les analyses. Reproduire signifie conserver les entrées, les versions et les résultats observés. Ce chapitre recommande de publier ces éléments avec une limite claire sur ce qui n’a pas été exécuté.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
