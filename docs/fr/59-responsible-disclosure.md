# Divulgation responsable

Dans `SECURITY.md`, ce travail étudie le canal de signalement et le périmètre attendu. La fiche précise le contexte, la donnée vérifiable et la limite d’interprétation afin qu’un lecteur puisse reproduire l’examen sans confondre un indicateur avec une preuve complète. Elle s’inscrit dans la documentation professionnelle du compte CryptoAstuce.

Aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
