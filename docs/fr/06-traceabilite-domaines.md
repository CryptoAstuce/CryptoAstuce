# Traçabilité par domaine

DOMAIN-EXAMPLES.md relie les exemples aux domaines Base, Hyperliquid, ZK et FHE. Cette structure évite de mélanger une propriété de protocole avec une hypothèse d’intégration. Chaque domaine doit conserver ses propres sources et conditions de validité.

Ce travail est documentaire et source-grounded : aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
