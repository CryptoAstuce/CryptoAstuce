# Limites du modèle

Dans `prototype/rollup_data_availability.py`, ce travail étudie ce que le prototype de disponibilité ne modélise pas. La fiche explicite la donnée observée, la condition de validité et le risque d’une interprétation trop large, pour conserver une documentation exploitable par un autre lecteur. Elle complète le parcours français sans revendiquer de résultat non observé.

Aucune installation, compilation, exécution de test ou transaction n’a été réalisée.
